# Правила для Claude Code в этом репозитории

- Сайт лежит в папке `site/`. Править только там.
- После правки: `git add -A && git commit -m "<что изменили, по-русски, одной фразой>" && git push`.
  Описание коммита попадёт в журнал выкладок, пиши его понятно для владельца сайта.
- Перед push запусти `./scripts/check-site.sh site` — это те же проверки, что пройдёт сайт перед выкладкой.
- Пароли, ключи и `.env` в репозиторий не класть.
- Если владелец просит вернуть прошлую версию: `gh workflow run deploy.yml -f rollback_to=<номер>`.
